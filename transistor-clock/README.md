# ساعت دیجیتال تمام‌ترانزیستوری (All-Discrete Transistor Clock)

نسخهٔ **کاملاً گسسته** از ساعت دیجیتال ۲۴ ساعته — **بدون هیچ آی‌سی**، بدون میکروکنترلر،
بدون آردوینو، بدون FPGA، بدون برنامه‌نویسی. همهٔ منطق (نوسان‌ساز، تقسیم‌کننده، شمارنده‌ها،
دیکودر ۷ سگمنت، درایورها) با **ترانزیستور 2N3904**، **دیود 1N4148**، مقاومت و خازن ساخته می‌شود.

> این پروژه جدا از نسخهٔ CMOS (`digital-clock`) ساخته شده تا نشان دهد ساخت یک ساعت
> **تماماً ترانزیستوری چقدر سخت است و آیا ارزش دارد یا نه**.

---

## پاسخ کوتاه: آیا ارزش دارد؟

| هدف | حکم |
|---|---|
| **ساعت عملی و قابل‌اتکا** | ❌ **ارزش ندارد** — ۱۲ برابر قطعه، ۱۰ برابر زمان ساخت، ۴ برابر هزینه، ۲ برابر مصرف، و **همان دقت** |
| **پروژهٔ آموزشی / هنری** | ✅ **ارزش دارد** — درک عمیق bistable، steering، DTL، ماتریس دیودی، race و reset |

**مسیر کم‌ریسک:** اول نسخهٔ CMOS را بساز؛ بعد فقط **یک سلول رقم** (~۲۰ ترانزیستور) و یک مرحلهٔ
تقسیم را روی بردبورد تست کن؛ اگر لذت بردی، گسترش بده.

| مقاومت / خازن | ۶۴۴ / ۱۰۶ |

## اجرا و بازتولید

```bash
# شبیه‌سازی منطق (۲۵ ساعت + مرزها + SET/reset)
node sim/verify.js

# بازتولید نت‌لیست + BOM (با assertionهای پوشش)
python netlist/gen_netlist.py

# بازتولید داشبورد HTML از netlist
python visuals/gen_assessment.py
```

خروجی `verify.js` باید به `ALL LOGIC VERIFICATION PASSED` برسد.
خروجی `gen_netlist.py` باید به `SANITY OK` برسد (پین یکتا، بدون نت شناور، بدون wire-OR).

## وضعیت راستی‌آزمایی (صادقانه)

| بخش | وضعیت |
|---|---|
| منطق شمارنده‌ها، معادلات سگمنت، پین‌اوت | ✅ تأییدشده (شبیه‌سازی + دیتاشیت) |
| سلول TFF آنالوگ، نوسان‌ساز پیرس، اشمیت، race ریست | ⚠️ **نیازمند SPICE + بنچ‌تست — تأییدشده اعلام نمی‌شود** |
| کل مدار روی سخت‌افزار | ❌ هنوز ساخته/تست نشده |

شبیه‌ساز رفتاری سه خطای واقعی در معادلات سگمنت را caught و اصلاح کرد
(ترم‌های `f` و `g` برای ارقام ۶/۷، و سگمنت `b` دهگان ساعت که باید همیشه روشن باشد).

- **2N3904**: ON Semi 2N3903/D Rev.9 (Aug 2021) — پین‌اوت TO-92 CASE 29 STYLE 1: `1=E, 2=B, 3=C`
- **1N4148**: ON Semi 1N914/D — کاتد = نوار مشکی
- **زنر 1N47xx**: Vishay 85816 Rev.2.7 (Nov 2024)
